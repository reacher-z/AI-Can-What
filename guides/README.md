# Choose resources for your goal

Choose by purpose, interaction setting and evidence boundaries. These guides are not quality rankings.

- [Find AI-built software](ai-built-software/README.md): Find games, websites and native apps with first-party AI-development statements, then distinguish code, demos and limited interaction evidence.
- [Test a browser agent](browser-agent-benchmarks/README.md): Compare browser-agent resources by interaction setting, scoring and setup: self-hosted sites, live-web evaluation, recorded trajectories and shared frameworks.
- [Test computer & phone use](computer-mobile-agents/README.md): Choose desktop VMs, Android/iOS research apps or static GUI datasets while keeping target OS, host requirements, scoring and access limits separate.
- [Evaluate software generation](software-generation/README.md): Compare webpage reconstruction and game-development benchmarks by supplied inputs, generated artifact, tested behavior and released evaluation materials.
